mimono shikaku

四角 / 視覚 — live GPU square halftone for websites

← Playground Quick start STUDIO URL params Adding assets Dither modes FAQ

mimono shikaku uses the stable <halftone-fx> component to render an image or video as animated square marks, live in the browser, on the GPU. Instead of exporting a heavy video file, you embed a tiny program: it stays razor-sharp on any screen, costs ~0.1 ms of CPU per frame, and a whole animated hero background weighs a few hundred kilobytes.

Quick start

  1. Open the playground.
  2. Pick a clip from Source (the list mirrors this repo's webgl/assets/ folder) and tune the sliders until it looks right.
  3. Click ⬇ Download PNG for a full-resolution still with transparency, or 📋 Export iframe for the live version.
  4. Use the PNG directly, or paste the iframe into your site builder's embed/HTML element.

Embedding in STUDIO (studio.design)

  1. In the STUDIO editor, open the 追加パネル (Add panel) on the left and add an 埋め込みボックス (Embed box) to your page.
  2. Select the box, open the settings panel on the right, and paste the code from Export iframe into the 埋め込みコード (embed code) field.
  3. Size and position the box like any element — for a hero background, make it fill the section and layer your text boxes on top. Keep its width and height equal for the default 1:1 shikaku composition.
  4. The editor canvas may show a placeholder instead of the animation — that's normal. Check プレビュー (preview), then 公開 (publish).
Keep the embed box to the single <iframe> tag. A standalone iframe gets STUDIO's clean "iframe type" embed; any extra HTML around it switches STUDIO to a restricted sandbox mode.
Backgrounds: the exported code includes pointer-events:none so clicks and scrolling pass through to your page. Remove it if the animation should be interactive. Set the bg param to your page's background color so the iframe edges are invisible. The exported iframe includes aspect-ratio:1/1 so the default box stays square.

URL parameters

The embed page is configured entirely by its URL — edit params and reload to restyle, no code changes ever:

https://playbox-dev.github.io/halftone-dithering-fx/webgl/embed.html?src=./assets/horse.mp4&grid=80&shape=square&size=42&threshold=50
ParamValuesMeaning
srcURLImage or video. Relative (./assets/…) or any CORS-accessible absolute URL. Add type=video for video URLs without a file extension.
grid8–160Halftone cell size in px. Larger = fewer marks. Default 80.
shapesquare / circleMark geometry. Default square; circle preserves the legacy look.
size0–100Maximum mark size within each cell. Lower values create more space between squares. Default 42.
threshold0–100Hides marks smaller than this percentage. Raise it to remove small peripheral squares. Default 50.
dothexMark color, without # (e.g. ff3110). Default mimono Play Red.
bghex / transparentBackground color. Default transparent.
brightness-100…100Raises or lowers source luminance. Default 12 for a lighter, sparser result.
contrast-100…100Default 0.
gamma0.1–3Default 1.
dithernone bayer4 bayer8 grain noiseSee dither modes. Default none.
multicolorflagRainbow marks colored by brightness.
Sparse mimono logo preset: grid=80, size=42, threshold=50, brightness=12. Grid controls how many squares appear; size controls the gap between them.

Adding your own image / video

Assets live in the repo, so they're versioned and served with correct CORS headers. To add one:

  1. Open webgl/assets on GitHub → Add file → Upload files → commit.
  2. Wait ~1 minute for GitHub Pages to redeploy.
  3. Reload the playground — the file appears in the Source dropdown automatically (the list is read live from the repo).
Keep files small — it's free. The halftone destroys fine detail, so a 640×360 heavily-compressed clip looks identical to 1080p. The marks are drawn by the shader and stay sharp regardless. Recommended encode: 
ffmpeg -i input.mp4 -vf scale=640:360 -c:v libx264 -pix_fmt yuv420p \
       -crf 30 -preset veryslow -movflags +faststart -an output.mp4
The two bundled clips are 97 KB (spiral) and 373 KB (horse).

Dither modes

For animation, temporal stability is what matters — a pattern that changes every frame reads as shimmer. All modes are stable except noise, which flickers on purpose:

ModeLook
noneSmooth tonal halftone — square size carries the tone. Best default.
bayer4Coarse retro print / CRT crosshatch.
bayer8Finer retro pattern, more tonal steps.
grainOrganic, editorial — blue-noise-like, no visible pattern.
noiseAnimated film grain, re-seeded ~30 fps.

Error-diffusion dithers (Floyd–Steinberg, Stucki…) are deliberately absent here: they're sequential (can't run on a GPU shader) and they shimmer on video. They live in the classic export tool for still images.

Performance

Measured head-to-head against the CPU original (same video, 1920×1080, Apple M2 Pro): CPU version 51.7 ms/frame (~19 fps max, one core pinned) vs WebGL ~0.07 ms/frame — about 700× faster, using under 1% of a 60 fps frame budget. Reproduce it: open bench.html, wait a few seconds, and read window.__results in the console.

FAQ

The animation doesn't show inside the STUDIO editor.
Expected — embeds render in preview and on the published site, not on the editor canvas.

bg=transparent looks white when I open the embed URL directly.
Expected — a standalone browser tab has nothing behind the page, so you see the browser's own default backdrop. The transparency is real: put the iframe on a page (or in STUDIO) and the page shows through between the marks. Both bg and background work as the param name.

The video doesn't autoplay.
Keep allow="autoplay" on the iframe. Playback is muted + inline, which all browsers permit.

Colors in the URL don't work.
Drop the # — write dot=ff3300, not dot=#ff3300.

Can I use a clip hosted elsewhere (not in this repo)?
Yes, if the host sends CORS headers (Access-Control-Allow-Origin). GitHub Pages does; most random hosts don't. When in doubt, commit it to webgl/assets/.

Does it work on phones?
Yes — WebGL2 is supported by all current browsers including iOS Safari, and the effect is far lighter than a CSS blur. The component also pauses itself when scrolled offscreen.
